# 0.0.64 — configuration panel and connection recovery

- Scope the server address widget against host-page table-layout overrides; support narrow cards.
- Distinguish checking/online/offline. Validate the health JSON, bound each GET to five seconds,
  coalesce overlapping probes, ignore superseded results, and retry every fifteen seconds
  while visible. Background checks never log in, refresh a page, or toggle automation.
- Connection testing updates local login/config in place instead of counting down to a page reload.
- Reject expired logins as Error objects; preserve a renewed login when an old 401 arrives late.
- Reject network failures with readable errors, suppress burst duplicates, and keep AI request
  timeouts separate from service health. Preserve quiet snapshot-request feedback.
- Render reply notices as plain text, without external avatar fetches or raw HTML insertion.
- Normalize helper panel/dialog/feedback layers and limit narrow-screen floating panels.
- Preserve personal mode, Chrome host permissions, delivery/ACK safety, and the existing backend.

Regression: unit and real Axios-interceptor fixture tests; TypeScript; CSP/protobuf checks;
isolated Chrome layout checks at 1170/700/360px. No real BOSS browser session is used by tests.

Deployment: install only after the matching GitHub Actions pass. Keep the extension ID/path
and back up the preceding package. Existing BOSS tabs require a user-controlled reload to
replace already-injected code; extension reload alone does not claim a live-page upgrade.
The unrelated staged Python API migration must not enter this frontend-only commit.
